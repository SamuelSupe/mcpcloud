## Readiness preflight (not acceptance)

Run `validate-config` first; it checks YAML and registered adapters without contacting cloud APIs. `cloud_profiles` is also configuration/readiness metadata and does not prove live access. When real credentials are available, run `probe-profile --profile NAME` for an individual profile or `probe-profile --all` for the configured set. The CLI performs a bounded fixed `resources` inventory read per selected profile with page size 100 and at most 10 cursors, emits only authentication/scope/capability evidence, and never emits resource rows or credentials. It returns JSON even for `degraded` and `not_ready`, but exits non-zero unless the aggregate status is `ready`.

The probe is intentionally not a principal-identity API. `authenticated` means the fixed inventory read completed. A profile is `ready` only when exactly one configured resources scope exists and that unique scope matches the observed scope. With multiple configured resources scopes, one observed match is insufficient: the result is `degraded` with `identity_status` `authenticated_partial_scope_evidence`; a successful read with no matching scope is `degraded` with `authenticated_scope_unverified`. Scope matching is declaration-type strict, including Huawei project scopes matching only `project_id` and Huawei account scopes matching only `account_id`. Aggregate `--all` status is `ready` only when every selected profile is ready, `degraded` when at least one profile is reachable but evidence is incomplete, and `not_ready` when none is reachable.

`/readyz` is the server-side form of this preflight. It refreshes the fixed probe only after its one-minute TTL expires, returns HTTP 200 for `ready` or `degraded`, HTTP 503 for `not_ready` or probe failure, and returns only aggregate counts and cache timestamps. It does not return profile rows, credentials, or principal identity data. Neither the CLI probe nor `/readyz` replaces the seven-provider live resource matrix, representative metric/cost checks, or provider audit-log acceptance.
