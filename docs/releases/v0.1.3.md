# MCPCloud v0.1.3

发布日期：2026-10-29。

修复 `/readyz` 探测函数返回错误时未建立缓存的问题，避免连续健康检查请求重复触发云探测。

## 修复

- 探测报告和探测错误均从本次探测完成起缓存一分钟；TTL 内的请求复用结果，并发请求共用一次刷新。
- 缓存过期后的首次请求重新探测，探测恢复后返回新的就绪状态。
- 探测错误仍返回 HTTP 503 和脱敏的 `probe_failed` 错误码，不暴露底层错误内容。

## 文档与验证

同步更新 README、配置与安装说明、平台说明、发布命令及 changelog。新增回归测试覆盖首次失败、TTL 内复用错误、过期后成功恢复；探测与 HTTP 服务测试已在 OrbStack Linux 上通过并发竞争检查。

继续提供 Windows amd64 / arm64 和 Linux amd64 / arm64 四种程序包。发布工作流在对应架构的 GitHub 虚拟机上检查解压包的版本、源码提交、MCP 握手和 HTTP 安全边界；每种包的验证结果随 Release 发布。本次验证不调用真实云账号，不代表重新完成七云接口联调。

v0.1.2 的分页、作用域和时间边界修复继续保留。该版本的修复详情见 [v0.1.2 更新说明](https://github.com/SamuelSupe/mcpcloud/blob/v0.1.3/docs/releases/v0.1.2.md)。
