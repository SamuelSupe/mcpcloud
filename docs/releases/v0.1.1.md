# MCPCloud v0.1.1

新增 Windows ARM64 程序包，并为 Windows / Linux 的 amd64、arm64 四种程序包补充独立虚拟机启动验收。原有七云查询功能沿用 v0.1.0。

| 平台 | 程序包 | 验证环境 |
| --- | --- | --- |
| Windows amd64 | ZIP，适用于 Intel / AMD x86_64 | GitHub Windows Server 2025 虚拟机 |
| Windows arm64 | ZIP，适用于 ARM Windows | GitHub Windows 11 ARM64 虚拟机 |
| Linux amd64 | TAR.GZ | GitHub Ubuntu 24.04 x86_64 虚拟机 |
| Linux arm64 | TAR.GZ | GitHub Ubuntu 24.04 ARM64 虚拟机 |

四个平台均执行实际解压包，核对版本、源码提交、配置加载、stdio MCP 握手 / 六工具目录、HTTP 健康、Bearer / Host 拒绝以及未注册写操作拒绝。ARM64 在匹配架构的运行器执行，不使用 QEMU；结果及对应工作流链接附于 Release。

新增只读权限的 GitHub Actions 工作流，不注入云凭证，不调用云接口，不自动部署或发布。发布包只含公开示例和固定白名单文件；附更新说明、依赖声明、构建清单、验证结果和 SHA256 校验。

安装、权限、启动、客户端接入及示例见 [使用说明](https://github.com/SamuelSupe/mcpcloud/blob/v0.1.1/docs/install.zh-CN.md)。Windows amd64 同时适用于 Intel 和 AMD，并非 AMD 专用；ARM Windows 使用 arm64 包。

本次仅补充发行平台与虚拟机验证，不表示重新完成七云云端验收。Azure 经典 Sponsorship 费用、账号侧账单条件、完整跨服务审计等 v0.1.0 已声明限制继续保留。Azure/GCP 测试环境未重建；既有部署未替换。Docker 镜像后续另行制作。
