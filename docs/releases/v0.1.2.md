# MCPCloud v0.1.2

修复跨云分页和时间边界问题，并加强 profile 作用域校验，避免查询静默漏数或越过配置范围。

## 修复

- **分页稳定性：** 阿里云、腾讯云费用分页，以及火山引擎资源中心、VKE 和网络详情分页，在 provider 侧使用固定页大小，再按 MCP 请求限制切分本地结果；分页游标因此不会随每轮剩余预算变化而错位。AWS ECS / ElastiCache 同样保留固定 provider 页并在本地继续。检测到不一致的页元数据、过早空页或重复游标时会返回错误，不再静默漏行或无限翻页。
- **AWS 区域端点：** ECS 和 ElastiCache 根据区域使用标准 AWS 或中国区域域名。
- **资源作用域：** 华为 OBS 按桶的实际地域执行 profile 限制；Azure 存储、AKS 节点池、节点和 Pod 详情及指标按资源实际地域校验。GCP 账单查询要求项目 scope 并下推 `project.id` 过滤；GCP folder scope、区域级 GKE 集群和全局资源（如 IAM）按其实际作用域处理。
- **时间窗口：** 腾讯云时间戳按北京时间解析；AWS Cost Explorer 使用包含请求结束日期的日期边界，避免同日查询报错或漏掉末日费用。
- **安全与稳定性：** `/readyz` 现在要求 Bearer Token 及 Host / Origin 校验；过滤错误最多返回 100 条并报告省略数量；火山引擎原生读取拒绝重复分页游标。华为 CES 发现支持翻页，DCS 空页不再重复返回当前游标，华为 OBS 请求签名支持 STS 安全令牌。

## 程序包与验证

继续提供 Windows amd64 / arm64 和 Linux amd64 / arm64 四个平台程序包。每个平台的解压包、版本、提交、MCP 握手和 HTTP 安全边界由发布工作流在匹配架构的 GitHub 虚拟机上验证；该检查不连接云账号，不代表云端接口已重新验收。

分页游标为不透明的版本化值。升级后请重新开始仍在进行的分页查询，不要继续使用旧版本游标。
