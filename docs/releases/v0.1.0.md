# MCPCloud v0.1.0

首次提供 Windows amd64、Linux amd64、Linux arm64 程序包及安装说明。Docker 镜像后续单独发布。

## 功能与修复

- 七云：AWS、Azure、GCP、阿里云、腾讯云、华为云、火山引擎的资源发现、固定只读详情、代表性监控与费用查询。具体能力随云、配置和账号权限不同，以 `cloud_schema` 为准。
- 修复资源分类、账号/地域匹配、Azure 权限清单漏项、阿里云标签过滤和 CPU 单位，以及 AWS ElastiCache 小分页等问题。
- 补齐节点/节点组、负载均衡后端健康、存储配置与统计等已验证的查询。
- 新增阿里云 OSS 桶权限、版本控制、生命周期和用量四项固定只读接口。
- 腾讯云显式限定 provider 时支持 5 秒 / 10 秒监控；已验证数据库 CPU 和云主机 CPU 代表样本，其余指标需云端支持。
- 新增 `mcpcloud version --json`，报告版本、源码提交、构建时间、Go 版本和目标平台；MCP 握手使用同一版本号。
- 提供可复用打包工具、无凭证的启动 / MCP / HTTP 认证检查、SHA256 校验及构建清单。

## 验证口径

七云主要功能沿用此前真实云端验收记录；OSS 和腾讯秒级增强另有合并后实测。Azure/GCP 专用测试环境已于 2026-10-20 回收，本次不新建收费资源。

本次交付包从解压目录验证版本与提交信息、配置校验、stdio MCP、六工具目录、HTTP 健康与认证拒绝路径。Linux ARM64 使用 QEMU 仿真，未声明 ARM 实机验证。发布资产附验证结果与校验值；打包启动检查不冒充七云重新全量验收。

## 已知限制

- Azure 经典 Sponsorship 验证订阅不支持所用费用接口，真实费用暂缓。
- 腾讯合作伙伴费用已验证；普通账单可见范围、付款归属与结算口径仍需账号侧确认。
- 完整跨服务云端只读审计证据尚未补齐。
- AWS 集群内部 Node/Pod/可调度容量、OSS 已启用版本控制/生命周期的正向真实样本仍待补验。
- HTTP 使用实例级共享 Bearer Token，没有内置每人独立账号及用户级云权限隔离；远程使用需 HTTPS 代理和访问控制。

发布不自动切换现有部署。升级前保留旧程序和配置；安装、权限、启动及客户端接入见 `docs/install.zh-CN.md`。
